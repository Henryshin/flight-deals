연차 아껴서 휴가가자!
📖 사용 메뉴얼
1. 특가율 = 시세 대비 얼마나 싼지 나타내는 지표. 통상 연휴 기간이라 가격이 비싸지만, 이를 모르고 있는 해외 항공사 혹은 프로모션 중인 항공사가 단 한개라도 있을 경우 나타나는 가격.
2. 연휴기간에 연차 끼워써야하는 직장인들을 위해 만든 사이트로, 다른날짜 검색이 필요한 경우에는 스카이스캐너 이용 권고.
3. 일정 옆 날씨(🌧/☀️/⛅)는 해당 기간의 평균 날씨
4. 보드는 두 가지 — 연휴 특가 보드는 "이 연휴엔 어디가 싼가", 여행지별 연휴 보드는 "이 여행지는 어느 연휴에 가야 싼가"를 봅니다.
5. 필터의 휴일 가치(하루 = n만원)를 설정하면, 조금 비싸도 주말·공휴일이 길게 이어지는 일정(예: 목금 연휴에 앞주말까지 9일 연속)을 실질 비용으로 비교해 추천합니다.
